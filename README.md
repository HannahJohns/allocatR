# allocatR

R package containing methods for randomly allocating participants in randomised clinical trials and simulating trials with these methods.

# How to install

The simplest way to install this package is to run the following code in R:

```
if (!require("devtools", character.only = TRUE)) install.packages("devtools")
devtools::install_github("https://github.com/HannahJohns/allocatR")
```
